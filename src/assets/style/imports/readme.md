### Глобальные импорты, автоматически вставляются в каждый scss файл

Сюда нужно помещать глобальные переменные, миксины, функции, которые должны быть доступны во всех стилях проекта.

### Структура:

| **index.scss** - точка входа, именно этот файл автоматически импортируется (не нужно импортировать его самостоятельно)\
| **\_{partial}.scss** - файлы для импорта в index.scss\
| - **mixins** - папка для хранения глобальных миксинов (добавь, если ее нет)\
| -- **index.scss** - добавь index.scss в папку и импортируй его в index.scss уровнем выше\
| -- **\_{mixin | collection}.scss** - отдельные части для импорта в index.scss этого уровня\
| - другие папки с каким-то логическим разделением, со структурой, описанной для миксинов

###Важно!

Сюда нельзя добавлять стили, которые компилируются в реальный css (стили для селекторов за пределами миксинов и функций) - они будут повторяться в каждом итоговом блоке стилей.
